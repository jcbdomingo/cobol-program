# COBOL Programs

The repository serves as a collection of my COBOL programs, exercises, and school activities. It also allows me to track my progress and keep my source code organized using Git and GitHub.

- COBOL source code (`.cob`, `.cbl`)
- Input and output text files (`.txt`)
- Programming exercises and activities

- Visual Studio Code
- WSL Debian
- Git and GitHub
